# Borrador de difusión de Data Mesh

## Para qué sirve

La página [My data mesh thesis](https://carlosgrande.me/resources/thesis/my-data-mesh-thesis/) reúne conceptos, principios y referencias sobre Data Mesh. Esta propuesta presenta el recurso a profesionales de datos y les invita a compartir cómo entienden el reparto de responsabilidades entre equipos. Es un borrador para revisión del propietario: no se ha publicado ni se ha comprobado la titularidad o el acceso a los perfiles.

## Texto propuesto para LinkedIn

¿Cómo organizamos la responsabilidad de los datos cuando varios equipos los producen y consumen?

Preparé esta tesis como una guía para entender Data Mesh: recoge sus principios, una visión de arquitectura, posibles formas de implementación y referencias para seguir aprendiendo. Mi intención era ordenar las distintas interpretaciones que encontraba sobre este enfoque.

Puedes consultarla aquí: https://carlosgrande.me/resources/thesis/my-data-mesh-thesis/

Si trabajas con equipos de datos, ¿qué te ha ayudado a definir quién es responsable de cada producto de datos?
