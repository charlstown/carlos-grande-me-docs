The workflow

My AIsy Toolkit

SDD + agentic loops, in one tool.

Diagram of the My AIsy Toolkit feature loop, arranged like an athletics track around the constitution. /specify-feature scopes the work against the project's constitution — a living set of product-spec, tech-spec and roadmap documents. /specify-feature hands off to /plan-feature, which breaks the work into eight tasks across two features, each in the @agent · task format and assigned to a subagent from the catalog. All eight tasks converge on /implement-feature, which runs the plan in its own isolated git worktree and feeds directly into /clean-feature, which reconciles the specs and closes the loop back to the constitution, ready for the next feature.

/constitution scaffolds the specs every skill in the loop reads from and writes back to.

/specify-feature scopes what you're building and why into a requirements file.

/plan-feature breaks the requirements into tasks, assigned to the right subagent.

/implement-feature builds the plan inside its own isolated git worktree.

/clean-feature updates the specs to match what shipped, and closes the loop.
